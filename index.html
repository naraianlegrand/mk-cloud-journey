Our Journey Begins

This website marks the first milestone in our cloud adventure. We are starting with foundational projects, like hosting this static website on Amazon S3, to build our expertise from the ground up. Follow along as we explore new AWS services, tackle complex challenges, and share our learnings with the community.

Phase 1: Foundation

Deploying a static website on Amazon S3 and configuring it for public access. This is where it all starts!

Phase 2: Serverless

Exploring data persistence with services like Amazon DynamoDB and managing files with S3 storage classes.
